# 한국어 설문 감정사전

`sentiment_ko.tsv`는 이 프로젝트에서 작성한 한국어 설문용 규칙 사전(v1.0.0)입니다. 외부 학습 데이터나 KNU 감성사전의 복제본이 아닙니다. 별도 다운로드 없이 패키지에 포함됩니다.

- `term`: 근거에 표시할 표제어. `aliases`: `|`로 구분한 추가 표현.
- `polarity`: -1~1의 규칙 가중치. 확률이나 검증된 심리 척도가 아닙니다.
- `urgency`: 처리 우선도 신호(0~1). `kind`: 감정, 요청 또는 시급성 표현.
- 사전과 입력을 Kiwi 형태소열로 비교하며 긴 표현을 우선합니다. 불만족/만족, 불친절/친절 중복을 방지합니다.
- `개선`, `필요`, `요청` 자체는 부정 감정으로 계산하지 않습니다.
- 부정 표현의 범위는 절·문장 경계 안으로 제한하고 부정된 감정은 약화하여 반전합니다.
- 문맥, 반어, 다의어, 간접 표현은 여전히 사람의 검토가 필요합니다. 사전 무적중을 긍정으로 처리하지 않습니다.

수정 시 버전을 올리고 `tests/fixtures/korean_analysis.json` 및 독립된 실제 라벨 자료로 점검하세요. 포함된 테스트는 회귀 검사이며 모집단 정확도를 입증하지 않습니다.
