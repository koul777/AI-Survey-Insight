# 0.2.0 — 한국어 토픽·감정 통합 분석

한국어 형태소와 감정 근거를 응답별로 보존하고, 중복 응답에 의한 토픽 과분할과 부정문 오판을 수정합니다.

## 변경 사항

- Kiwi 전체 품사열을 공유합니다. 토픽에는 주제 명사·영문 용어를 쓰고 감정에는 형용사·동사·부정어를 포함합니다. Unicode·제로폭·공백을 정규화하고 URL·마스킹 표시는 토픽 단어에서 제외합니다.
- 프로젝트에서 작성한 160항목 감정사전을 패키지에 포함합니다. 긴 표현 우선, 활용형, 부정·이중 부정, 강조·약화, 절 경계를 처리합니다. 근거 없는 응답을 별도 상태로 표시합니다.
- 동일 문장은 한 번 적합하고 원래 응답 수와 감정 분포를 복원합니다. 주제 단어가 없으면 토픽 미배정으로 남기면서 감정분석을 유지합니다.
- NMF·LDA의 문서–토픽 가중치와 하드 군집의 상대적 중심 유사도를 공개합니다. 모든 후보의 분리도는 동일한 공간에서 평가합니다. c-TF-IDF는 실제 정수 빈도를 사용하며 키워드가 소속 응답을 설명하는 비율도 평가합니다.
- 설치한 Multilingual E5를 네트워크 없이 선택적으로 사용합니다. 설치 명령만 모델 파일을 다운로드하고 revision을 기록합니다. 실패하면 명시적 경고와 함께 형태소 토픽모델로 돌아갑니다.
- 긴 응답은 480토큰 구간을 모두 인코딩해 결합합니다. 5,000문장 초과에는 MiniBatch NMF와 MiniBatch KMeans를 비교하고 1·2·3개 토픽도 후보에 유지합니다.
- 응답별 감정 조회·필터, 토픽별 감정 분포, 근거 포함률을 UI/API/Excel에 연결합니다. 저장 후 다시 열어도 유지되며 토픽 병합 시 감정 분포를 재계산합니다.

## 검증 범위

- Windows / Python 3.12에서 Kiwi 0.23.2·0.24.0 각각 전체 테스트 100개 통과. `split_complex`와 기본형 어미 정규화로 버전 간 파생어 분석 차이를 처리합니다. GitHub Actions는 Python 3.11·3.12를 별도로 확인합니다.
- 자체 감정 회귀 예제 32개: 기존 12개 정답 → 32개 정답. 개발에 사용한 예제이며 외부 정확도 측정이 아닙니다.
- 교육·급여·시설 24개 예제: 세 주제 회복 ARI 1.0. 3회 반복 자료에서도 세 주제 유지.
- 실제 E5 모델(384차원) 로컬 추론과 의미 후보 생성 확인.
- 6,000행 통합 분석: 약 41초, 세 주제 복원 ARI 1.0, 긍정 4,000·부정 2,000건 집계. 세 문장 템플릿에 번호를 붙인 처리량 검증이며 다양한 실제 문장의 품질 검증은 아닙니다. 실행 시간은 하드웨어·동시 작업에 따라 달라집니다.
- 카카오톡 실제 입력의 전처리·분석 완료 확인. 대화 데이터의 낮은 분리도와 안정성을 성공으로 포장하지 않고 경고로 표시.
- API 업로드·분석·감정 필터·페이지 조회, SQLite 복원, 보고서 개인정보 제외, 사전 패키징과 네트워크 차단 동작을 검사.
- UI JavaScript 구문·렌더링·이벤트 연결 검증. 실행 환경에서 연결 가능한 브라우저가 없어 화면의 시각 검수는 수행하지 못함.

회귀 검증은 `python scripts/benchmark_analysis.py --stress-rows 6000`으로 재현할 수 있습니다. 출력 JSON에는 원문 대신 지표와 설정만 저장합니다.

## 해석 시 구분할 값

감정 점수는 사전 규칙의 극성 신호이며 확률이 아닙니다. `neutral`은 감정 근거가 없는 응답도 포함합니다. `evidence_status`, 근거 구간, 분포와 함께 검토하세요. 반어·다의어·간접 표현을 완전히 이해하는 모델은 아닙니다.

토픽 건수와 감정 분포는 전체 응답 빈도 기준입니다. 모델 평가와 bootstrap은 중복 제거한 문장 기준입니다. 두 단위는 `analysis_diagnostics`와 후보 `params`에 명시합니다.

NMF 가중치·LDA 사후 가중치·상대 중심 유사도는 서로 다른 방식으로 계산됩니다. `score_method`를 확인하세요. 높은 소속도는 높은 분류 정확도를 의미하지 않습니다.

## 설치와 실행

```powershell
python -m pip install -e .
python -m survey_insight.cli setup-local-model
python -m uvicorn survey_insight.api:app --host 127.0.0.1 --port 8001
```

모델 설치는 선택 사항입니다. 설치하지 않아도 NMF·LDA와 감정사전 분석은 작동합니다. 다운로드한 모델과 실제 사용자 원본·DB·보고서는 릴리스에 포함하지 않습니다.
