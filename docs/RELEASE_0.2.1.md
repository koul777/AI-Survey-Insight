# 0.2.1 — 문맥 해석·토픽 계산·분석 이력 보완

한국어 간접 부정과 해결 요청의 감정 오판, NMF 성분 배율에 따른 배정 변화, 토픽 편집 후 이전 품질 점수가 남는 문제를 수정합니다.

## 바뀐 동작

- `부족한 점이 없다`, `도움이 안 된다`의 부정 범위를 처리하고 `문제 해결이 필요하다`를 해결 완료로 읽지 않습니다. `업무 지침`, `안전 교육` 등 중립적인 언급도 구분합니다.
- 인용·가정·희망·간접화법·반어 가능성은 검토 사유를 표시합니다. 감정사전은 프로젝트 작성 160항목/1.0.0 그대로이며 적용 규칙 버전은 1.1.0입니다.
- NMF의 W·H 재구성값을 보존하면서 성분 배율을 정규화합니다. 영벡터는 이상치로 남기며 MiniBatch 재적합은 동일 알고리즘을 유지합니다. LDA의 최소 단어 수는 unigram으로 셉니다.
- 기존 UMass 스타일 값과 별도로 희귀어 평활 보정 진단을 제공합니다. 선정 복합 점수에는 추가하지 않습니다.
- 짧은 실질 대화를 보존하고 NFKC 반응 자모를 제거합니다. 맥락 구간마다 원본 데이터 행을 추적하며, 건수는 사람 수가 아닌 구간 수임을 표시합니다. 여러 발화자가 섞이는 대화의 집단 교차표는 만들지 않습니다.
- 토픽 병합·제외 후 현재 분포·소속도·설명을 갱신합니다. 편집 전 모델 진단을 보존하되 현재 결과는 미평가로 표시합니다.
- Excel 문자열의 수식 해석과 금지 제어문자를 막고 대표 의견·편집 이력을 마스킹합니다. 소수 셀의 건수·감정과 해당 그룹 전체 비율을 함께 숨깁니다.
- 기존 SQLite 결과는 저장값을 바꾸지 않고 읽습니다. 과거 대화의 분석 단위를 복원하며 기록되지 않은 원본 행 번호는 추정하지 않습니다. 새 규칙을 적용하려면 다시 분석해야 합니다.

## 품질 측정의 범위

Windows / Python 3.12에서 Kiwi 0.23.2·0.24.0 각각 전체 테스트 140개를 통과했습니다. Chrome에서 샘플 업로드·분석 실행·이력 복원과 권장안 화면을 확인했고, 좁은 화면에서 카드가 잘리던 배치를 수정했습니다. UI의 편집 후 미평가·대화 단위·검토 사유는 JavaScript 렌더 검사로도 확인했습니다. Office 출력은 OOXML 구조와 내용 검증 범위이며 Office 앱 화면 검수는 포함하지 않습니다.

고정 감정 도전 40문장은 19/40에서 40/40으로 기대 라벨과 일치했고, 그중 16개는 문맥 검토 대상으로 남습니다. 별도 모호한 8문장의 검토 표시는 2/8에서 8/8로 늘었습니다. 최소쌍 25개와 부정형태 조합 24개도 회귀에 포함합니다. 모두 개발에 사용한 프로젝트 작성 자료로 외부 정확도가 아닙니다.

반복 어휘가 적은 새 자료의 결과도 함께 공개합니다. 넓은 분석자 분류와의 ARI이며 유일한 정답 토픽 수를 뜻하지 않습니다.

| 개발 진단 자료 | 0.2.0 | 0.2.1 |
|---|---:|---:|
| 24문장·단어 기반 | 0.019 | -0.032 |
| 24문장·로컬 E5 | 0.504 | 0.504 |
| 불균형 20문장·로컬 E5 | 0.579 | 0.579 |

NMF 계산의 정합성 수정이 모든 코퍼스의 의미 분류 개선을 뜻하지는 않습니다. 단어 기반의 낮은 품질은 검토 필요로 표시되며, 실제 대화도 분리도와 재표본 진단을 확인해야 합니다.

로컬 실제 대화 재실행에서는 2,484개 입력 행에서 2,228개 메시지·197개 맥락 구간을 구성해 5개 NMF 토픽 후보를 만들었습니다. 분리도 0.000, 부분표본 ARI 0.567, bootstrap 구조 관문 통과율 0.754로 검토 필요 상태입니다. 전처리 단위가 달라져 이전 169개 구간 결과와 같은 표본의 성능 향상으로 비교할 수 없습니다. 원문은 공개하지 않습니다.

```powershell
python -m unittest discover -s tests -v
python scripts/benchmark_topic_diagnostics.py --local-embeddings --out out_benchmark/topic_diagnostics.json
python scripts/benchmark_analysis.py --out out_benchmark/regression.json
```

설치 파일과 소스 ZIP에는 사용자 원문·DB·보고서·모델 가중치를 포함하지 않습니다. 체크섬과 빌드 기준 커밋은 릴리스의 manifest에서 확인할 수 있습니다.
